# CSC 372 - Assignment 1
## Title
> Realton Community Events Blog

## Description 
> This website is a place for our fictional community correspondent, JJ Miller, to highlight public events such as festivals, markets, exhibitions, educational programs, sporting events, concerts, or community celebrations.

## App Functions
###### Home Page
1. Has a working link to `event.html`.
2. Contains at least 30 lines of properly formatted HTML and uses at least five different HTML elements inside the body.
3. Includes substantial original text and avoids copying significant portions of `event.html`.

###### Event Page
1. Uses the format: `Community Spotlight: <Event Name>`
2. A minimum of three sentences are used to describe each event.
3. Uses an ordered list `<ol>` containing at least five specific activities, attractions, or program components and avoids vague entries such as "fun activities."
4. Uses an unordered list `<ul>` containing at least four practical tips. Topics include parking availability, accessibility features, childrens' activities, and popular nearby dining locations.

###### Main Image
1. Image stored in `images/` folder.
2. Uses a relative path to display it.
3. Includes meaninful alternative text and verified by Lighthouse.
4. Image named `[event-main.file type]`

###### Return Link
1. Includes a clearly labeled link back to `index.html` called "[text for link]"
