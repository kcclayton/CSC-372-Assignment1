# Assignment 1: Community Event Guide
### Purpose

Create a small website for a fictional community correspondent who highlights a real public event, such as a festival, market, exhibition, educational program, sporting event, concert, or community celebration.

By completing this assignment, you will practice basic HTML structure, navigation, external CSS, relative file paths,
images, lists, quotations, code validation, independent feature exploration, and GitHub Pages deployment.

### Required Files and Organization

| File       | Purpose                                                                                                  |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| index.html | introduces the community guide and links to the featured event.                                          |
| event.html | Presents complete information about one real public event.                                               |
| style.css  | Contains all required styles for the website. Inline styles and embedded style blocks are not permitted. |
| images/    | Stores all images used by the website.                                                                   |

Store the files in one project folder. Place all image assets inside the images subfolder and use relative paths.

### Part 1: Create the Home Page

Create index.html as the homepage of the community events website. It must meet all of the following requirements:

1. Include a working link to event.html.
2. Contain at least 30 lines of properly formatted HTML and use at least five different HTML elements inside the body.
3. Include substantial original text and avoid copying significant portions of event.html.

### Part 2: Create the Event Page

Create event.html about one real event. The page must contain the following items.
###### 1. Main Heading

Use this format: `Community Spotlight: <Event Name>`

###### 2. Required Content Sections

1. Event Overview: three-sentence paragraph to describe the event.
2. Featured Activities: Ordered list containing at least five specific activities, attractions, or program
components. Avoid vague entries such as “fun activities.”
3. Attendee Tips: Unordered list containing at least four practical tips. Possible topics include arrival time,
parking, admission etc.

###### 3. Main Image

- [ ] Store the image in the images folder.
- [ ] Use a relative path to display it.
- [ ] Include meaningful alternative text.
- [ ] Name the image event-main.jpg, event-main.png, or event-main.jpeg.

###### 4. Return Link

Include a clearly labeled link back to index.html, such as “Return to the Community Guide Home Page.”

### Styles:

###### Headings

- Main heading: bold 22pt font.
- Subheadings: normal-weight 18pt font.
- Underline every heading.
- Set every heading to #A4A400.

###### Page Text

`background-color: white;
`color: #404040;
`font-size: 11pt;
`font-family: Georgia, Garamond, serif;
``
### Exploratory Features

Complete Feature 1 and at least two of the optional features on event.html.

###### Feature 1: Attendee Testimonial

Include a fictional testimonial of one or two sentences inside a blockquote. At least one important word or phrase must
be bold.

- Display the blockquote in italic text.
- Indent the blockquote and use #FFFFA8 as its background color.
- Include at least one bold word or phrase in the testimonial.

###### Option 1: Repeating Background

Use a second event-related image that repeats in both directions and remains fixed while scrolling.

###### Option 2: Favicon

Add a small event-related favicon.

###### Option 3: Custom List Marker

Replace the normal Attendee Tips bullets with a small ticket, calendar, star, or map-marker image.

###### Option 4: Tooltips
Add a tooltip to each Featured Activity giving its start time, venue area, audience, or admission requirement.
